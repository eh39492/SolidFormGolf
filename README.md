# SolidFormGolf

WHAT:
A fully 3D-printed modular mini golf game. Contains many attachments so you can make whatever course you like! Includes 3 courses on one board: downhill, uphill, and flat, with modular slots for various pieces.
HOW:
Access using this Onshape link: https://cad.onshape.com/documents/887916e971dfccf44a02969f/w/f2c156957d22e0ce0922d3ab/e/75baa983d685b0c96256e83e?renderMode=0&uiState=6af0d53ef01e90fcae284c83
Then download, slice, and print!!!
HOW TO USE:
Choose a side and put the ball on the tee. Then customize your course by inserting the pegs into the holes. If you want a flat area, just use the squares. Play the round. To change the course layout, just turn the course upside down.
Made entirely in Onshape using tools like extrude, sketch, and plane.
